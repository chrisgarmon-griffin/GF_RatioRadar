## Intentional geometry differences

Property photographs retain editorial crop heights and the featured property spans two columns. These are media-composition choices, not comparable text-card height differences. Text-heavy panels retain intrinsic height. Inputs and results have different content lengths and are not forced to equal height. Pills, circular portraits, inner input corners and outer cards serve different roles and retain different radius types. Borders, type metrics, image crops and decorative radar positions are independent of the content-spacing scale. Inline links inside disclosure prose retain inline text hit areas; they are not standalone button controls.

The property explorer has a sample-data notice before its introduction. Other page introductions use the common page-start token. Native form controls, font rasterization and fractional CSS-pixel grid distribution can differ between engines; the checks assert usable shared geometry, not byte-identical screenshots.

## Remaining validation limits

Native Windows rendering, native Safari and native Edge were not available. Playwright WebKit is useful engine coverage but is not a claim that native Safari was tested. Zoom checks exercise equivalent CSS viewport reflow and text enlargement, not the native browser zoom menu. The width sweep samples intermediate widths; it is not an exhaustive proof for every possible width or content value. Automated axe checks and keyboard regressions do not establish complete WCAG conformance or replace assistive-technology testing. Those external checks remain open before claiming every acceptance criterion in the supplied brief is satisfied.
